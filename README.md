# Testgarten

Die komplette Website befindet sich in [index.html](./index.html).

So öffnen Sie sie lokal im Browser:

1. In das Projektverzeichnis wechseln
2. `python3 -m http.server 8000`
3. Danach in einem Browser `http://localhost:8000` aufrufen

Wenn nur diese README angezeigt wird, wurde nicht die HTML-Seite, sondern die Projektbeschreibung geöffnet. Die echte Homepage ist [index.html](./index.html).
